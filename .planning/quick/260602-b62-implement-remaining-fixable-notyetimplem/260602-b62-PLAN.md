## Implementation — `init_guess` cartesian `cart2sph` branch

Port upstream `Mole.cart2sph_coeff()` (`pyscf/gto/mole.py`) + the cart branch of
`init_guess_by_atom`/`init_guess_by_huckel` (`pyscf/scf/hf.py:528-531`).

- The atomic RHF (`get_atm_nrhf`) is always spherical (`atom_hf.rs:114`), so for a
  cartesian molecule the per-atom density block is in **spherical** AO count.
- Build the block-diagonal molecular density in **spherical** space
  (`nao_sph × nao_sph`), then transform to cartesian:
  `D_cart = C · D_sph · Cᵀ`, where `C = cart2sph_coeff` is the block-diagonal
  `[nao_cart, nao_sph]` matrix of per-shell `cart2sph(l, normalized='sp')`.

### Tasks

**Task 1 — molecular `cart2sph_coeff` builder**
- files: `crates/pyscf-scf/src/init_guess.rs` (or a small `cart2sph.rs` helper)
- action: walk `mol._bas` (per shell: l from `ANG_OF`, nctr from `NCTR_OF`),
  tile the per-l `[ncart(l), nsph(l)]` block (`normalized='sp'`) onto the
  block diagonal → `[nao_cart, nao_sph]`. Reuse the kernels' validated c2s
  coefficients (expose `c2s_coeff`/a per-l matrix as needed) so the convention
  matches the F-02-validated cart→sph transform; apply the `'sp'` normalization

- verify: `C` has shape `[mol.nao_nr (cart), nao_sph]`; for a spherical mol the
