  <name>Task 2: 15-VERIFICATION.md</name>
  Sections, in this order:

  * **§1 Per-criterion table** — one row per gate from `15-CONTEXT §2` (as
    restated by 15-01), with: the criterion, the exact command, the observed
    number, the tolerance, and `MET` / `PARTIAL` / `NOT MET`. **Never write
    "passes" without the number.**
  * **§2 Reference-value index** — every committed constant in Phase 15's tests,
    with the snippet that generated it and the file it lives in. Phase 13 and 14
    both did this and it is what makes a number auditable a year later.
  * **§3 What the phase's own tests caught** — the defects found during
    implementation, each with what it was worth in Hartree or in wrong indices.
    Phase 14 found six this way; the section is not optional and "none" is a
    legitimate answer only if it is true.
  * **§4 Premises that turned out wrong** — 15-CONTEXT already records three
    corrections to `PBC-MASTER-PLAN §8.7` made *before* implementation
    (`kconserv` already shipped, 15-02 largely shipped by 14-05, KUMP2's kernel
    absent upstream) and 15-01 restated two gate numbers. Record any *further*
    corrections implementation forced, and — the useful part — say which of the
    original three would have cost a rewrite if they had been found later.
  * **§5 Deferred branches** — a table of every `NotYetImplemented` this phase
    ships, with the phase that owns it. Expected entries: `ktensor` (17),
    `KPoints`/IBZ construction in `KMP2.__init__` (17), `KUMP2::kernel`
    (upstream — not this port), `kump2::_add_padding` (upstream),
    `kmp2_stagger` non-submesh branch (12, if `vcut_sph` is still open),
    `dimension == 2` in `_init_mp_df_eris` (upstream), `Frozen::{Auto, Window}`
    at k-points.
  * **§6 Carry-overs into Phase 16** — at minimum: `KptsHelper::build_symm_map`
    now exists and KCCSD should use it rather than recomputing orbits;
    `Eri7d`'s index contract is stable and Phase 16 inherits it unchanged;
    whether the `WorkspacePool` arena was needed at Phase-15 sizes (KCCSD's
    `Wvvvv` is `nkpts³ × nvir⁴` and will need it regardless).
  * **§7 Standing caveats** — the Ångström/Bohr CODATA gap for any new
    reference cell, and the two-route rule from `15-CONTEXT §2.2` (gate each DF
    route against its own upstream number).
  * **§8 The performance ledger (D-PBC-27, 15-CONTEXT §7)** — one small table,
    separate from the correctness gates: the upstream DF-vs-non-DF wall-clock
    ratio (15-01 Task 7) next to the port's own (15-05 test 7b); confirmation
    that `Lov`'s block build and the `KMP2` `(ki,kj)` loop measurably
    parallelise under rayon, not merely stay bit-identical while parallel
    (15-04 test 9b, 15-05 test 12); and `build_symm_map`'s measured `O(nkpts³)`
    growth curve (15-02 test 7) with a one-line statement of whether it is a
    concern at the k-meshes Phase 16 is expected to use. A blank row here reads
    as "never measured," the same failure mode the correctness gates exist to
    prevent, applied to speed.
</task>
