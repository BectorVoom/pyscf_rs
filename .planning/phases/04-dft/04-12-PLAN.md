<objective>
Fix BLOCKER CR-04: The KS energy cache in `hooks.rs` and `df_dft.rs` uses `Σ|D|` (L1 norm) with absolute 1e-12 tolerance as the cache key. This is non-injective — two different density matrices can have the same L1 norm. At µHartree convergence (exactly where the 1µH bit-exact gate operates), SCF step-to-step changes in `Σ|D|` can fall below 1e-12 while Exc has genuinely changed, causing a stale XC energy to be returned.

Purpose: Replace the `Σ|D|` fingerprint with an injective content hash of the density matrix data. Both `hooks.rs` (KsHooks cache) and `df_dft.rs` (DfKsHooks cache) must use the same fix. No new external dependency — use `std::collections::hash_map::DefaultHasher` (std Hasher) or an equivalent no-dep approach.

Output: Modified `hooks.rs` and `df_dft.rs`; new test `dm_fingerprint_is_injective` proving two matrices with the same L1 norm produce different fingerprints.
</objective>

The new fingerprint function (no new deps, stdlib only):
```rust
fn dm_fingerprint(dm: &Density) -> u64 {
    use std::hash::{Hash, Hasher};
    use std::collections::hash_map::DefaultHasher;
    let mut h = DefaultHasher::new();
    for &v in &dm.data {
        v.to_bits().hash(&mut h);  // bit-exact: NaN variants hash differently, -0.0 != 0.0
    }
    h.finish()
}
```
Cache hit condition becomes exact equality: `c.dm_fingerprint == dm_fingerprint(dm)`.
