<objective>

**Fully light up DF-MP2 (MP2-04) by making the DF 2-center metric factorization
robust — a focused pyscf-algebra task.**

05-08 closed the cintx#11 ERI gate: `int2e` and `int3c2e_sph` now evaluate for
real, and in-core RMP2 numeric is proven in-tree. The ONE remaining blocker for
DF-MP2 (and DF-HF) numeric is the 2-center metric decomposition: `cholesky_eri`
uses a plain Cholesky-Banachiewicz that rejects the ill-conditioned `(P|Q)`
metrics produced by real auxiliary bases (cc-pvdz-jkfit AND the weigend
universal aux are rank-deficient — confirmed in 05-08 even for H2).

The fix is exactly what upstream PySCF does (`pyscf/df/df.py` build): try a
Cholesky and, when the metric is not positive-definite, fall back to an
eigendecomposition that drops eigenvalues ≤ `LINEAR_DEP_THRESHOLD` and builds a
rank-revealing inverse-square-root fit. pyscf-algebra is the algebra-wall single
owner of host eigh/cholesky (faer 0.24), so the reusable primitive lives there;
`cholesky_eri` keeps its fast PD path and adds the fallback.

**Math:** the DF B-tensor satisfies `Σ_k B^k_μν B^k_λσ = (μν|·)ᵀ (P|Q)⁻¹ (·|λσ)`.
With a fit factor `W` (n×rank, `W·Wᵀ = (P|Q)⁻¹_trunc`), `B^k_μν = Σ_P (μν|P)·W[P,k]`.
- PD: `(P|Q)=L·Lᵀ` ⇒ the existing forward-substitution gives `B = L⁻¹·int3c` (rank=naux).
- Rank-deficient: `(P|Q)=V·diag(w)·Vᵀ`, keep `w_i > lindep` ⇒ `W = V_kept·diag(w_kept^{-1/2})`, rank=#kept.

**No new crate dep** (faer already in pyscf-algebra). **libxc NEVER compiled** —
the test scope (`pyscf-algebra`/`-df`/`-mp2`) does not pull pyscf-dft.

**df_metric_fit contract (NEW, pyscf-algebra):**
- in: `j2c` row-major n×n symmetric PSD, `n`, `lindep` (eigenvalues ≤ lindep dropped).
- out: `(w, rank)` where `w` is **column-major** n×rank (element (P,k) at `w[k*n + P]`),
  rank = #{eigenvalues > lindep}, and `w·wᵀ == (P|Q)⁻¹` on the kept subspace.
- `Singular` if rank == 0; `ShapeMismatch` if `j2c.len() != n*n`.
- Const `DF_METRIC_LINEAR_DEP: f64 = 1e-9` (matches upstream PySCF df lindep order;
  exact value reconfirmed when the upstream oracle runs).

**cholesky_eri consumption (pyscf-df):**
- Keep `cholesky_banachiewicz_lower` + `forward_substitute` PD fast path UNCHANGED
  (existing `cholesky_identity` etc. tests stay green; PD metrics match upstream
  Cholesky route bit-for-bit).
- On `Err(SingularAux)`: `let (w, rank) = pyscf_algebra::df_metric_fit(&int2c.values, naux, DF_METRIC_LINEAR_DEP)?;`
  then `b_uvq[μν,k] = oracle_dot(int3c(μν,·), w[:,k])`, `DfIntegrals { b_uvq, naux: rank, nao }`.
  Column k of `w` is contiguous (`w[k*n .. k*n+naux]`) for oracle_dot; gather
  int3c(μν,·) (F-order, stride nao*nao) into a contiguous naux buffer first.
