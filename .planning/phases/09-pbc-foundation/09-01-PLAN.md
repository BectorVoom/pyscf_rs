<objective>
Create the 19 `pyscf-pbc-*` crate stubs, wire them into the workspace, un-gate the
`pbc` forbidden-paths lint for those crates only, and buy down risk R-02 by proving
that `cintx` can evaluate a shell pair whose two shells come from different source
molecules (the mechanism D-PBC-07 depends on).

Nothing numerical ships in this plan. It is pure scaffolding + one risk probe.
</objective>

</context>

  <name>Task 1: Add 19 members to the workspace</name>
  1. `sed -n '1,30p' Cargo.toml` to see the existing members block and its comment style.
  2. Append the 19 paths from PBC-MASTER-PLAN §4, in the order given there, under a
     comment: `# v2.0 PBC milestone (D-PBC-*). Workspace grows 20 -> 39.`
  3. Do NOT add any new `[workspace.dependencies]` entries in this task.
</task>

<task type="auto">
  <name>Task 2: Create the 19 crate stubs</name>
  For each crate `pyscf-pbc-&lt;n&gt;`:
  1. `mkdir -p crates/pyscf-pbc-&lt;n&gt;/src`
  2. `Cargo.toml` from the PBC-MASTER-PLAN §4 template. Dependencies: ONLY crates that
     appear above it in the §4 DAG, plus `pyscf-core`, `pyscf-algebra`, `tracing`.
     `pyscf-pbc-df` additionally gets `hdf5-metno` (match the version `pyscf-ccsd` uses).
     `pyscf-pbc-mpi` gets an `mpi` feature, default OFF, with no default deps.
     FORBIDDEN in every one of these files: `pyo3`, any `cubecl-*`.
  3. `src/lib.rs`:
     ```rust
     //! pyscf-pbc-&lt;n&gt;: &lt;one-line purpose from PBC-MASTER-PLAN §4&gt;
     #![deny(unsafe_op_in_unsafe_fn)]
     #![warn(clippy::unwrap_used)]

     pub mod error;
     pub use error::*;
     ```
  4. `src/error.rs`: a `thiserror`-derived enum named `&lt;Crate&gt;Error` with a single
     variant `#[error(transparent)] Core(#[from] pyscf_core::PyscfRsError)`.
  5. `cargo build --workspace` must be clean after this task.
</task>

<task type="auto">
  <name>Task 3: Path-scope the forbidden-paths lint (RULE 7)</name>
  1. Read `xtask/src/bin/check_forbidden_paths.rs` in full.
  2. Add a predicate: if the scanned file's path contains `crates/pyscf-pbc-`, skip
     every needle for that file.
  3. Remove `"use pyscf::pbc"` and any other `pbc`-specific needle from the list, since
     `pbc` is now in scope for the milestone. Keep `x2c`, `mcscf`, `tdscf`, `adc`, `gw`,
     `eom`, `NAC`, `EPH` needles active for all non-`pyscf-pbc-*` crates.
  4. Update the failure message to cite `.planning/pbc/PBC-MASTER-PLAN.md §1` for the
     new scope boundary.
</task>

<task type="auto">
  <name>Task 4: R-02 risk probe — cintx cross-basis shell pair</name>
  Write `crates/pyscf-pbc-gto/tests/cintx_cross_basis_smoke.rs`:
  1. Build two `Mole`s from the SAME basis: `mol_a` = H at (0,0,0); `mol_b` = H at (0,0,2.0).
  2. Call `pyscf_gto::projection::build_combined_basis(&amp;mol_a, &amp;mol_b)`.
  3. Evaluate `int1e_ovlp_sph` for the shell pair `[0, mol_a.nbas]` (first shell of A
     with first shell of B) through `cintx_rs::SessionRequest`.
  4. Assert the value equals the (0, 1) element of `pyscf_gto::intor(&amp;mol_ab, "int1e_ovlp")`
     where `mol_ab` is a single Mole containing both H atoms — to 1e-12.
  If this test cannot be made to pass, STOP and escalate: D-PBC-07 and therefore all of
  Phase 10 is blocked. Record the outcome in the SUMMARY either way.
</task>

<task type="auto">
  <name>Task 5: Lint gates + design doc</name>
  1. `cargo run -p xtask --bin check_dependency_wall` — must pass.
  2. `cargo run -p xtask --bin check_forbidden_paths` — must pass.
  3. Write `xtask/tests/forbidden_paths_pbc_exempt.rs`: a fixture under a fake

  4. Copy PBC-MASTER-PLAN §2–§6 into `docs/design/pbc-architecture.md` so the
