<objective>
Land the `Cell` type: the periodic analogue of `Mole`. Per D-PBC-01 it OWNS a `Mole`
and `Deref`s to it, so `cell.nao_nr`, `cell.natm`, `cell._env` all work unchanged and
there is exactly one `Mole` build path in the workspace.

Also land the five shared reference systems every later PBC test uses.
</objective>

<task type="auto">
  <name>Task 3: lattice API (port cell.py:1811-1975 literally)</name>
  - `lattice_vectors(&amp;self) -&gt; [[f64;3];3]`
  - `vol(&amp;self) -&gt; f64` = `det(a).abs()`
  - `reciprocal_vectors(&amp;self, norm_to: f64) -&gt; [[f64;3];3]` = `inv(a.T) * norm_to`.
    **Port the `dimension &lt; 3` branch verbatim** — it zeroes the non-periodic rows.
  - `get_scaled_kpts`, `get_abs_kpts`, `get_scaled_atom_coords`
  - `tot_electrons(&amp;self, nkpts: usize) -&gt; usize` (port `cell.py:957-967`; the
    PP-adjusted charge arrives in plan 10-01)
  Implement `inv` and `det` for 3x3 by hand (closed form) — do NOT call faer for a 3x3.
</task>

<task type="auto">
  <name>Task 4: Cell::build</name>
  `pub fn build(args: CellBuildArgs) -&gt; Result&lt;Cell, PyscfRsError&gt;`:
  1. Delegate the molecular half to `pyscf_gto::build_from` on a fresh `Mole`.
  2. Convert `a` to Bohr if `unit` is Angstrom.
  3. Compute `rcut` (plan 09-04 provides `estimate_rcut`; until then use a
     `todo!()`-free placeholder that returns `NotYetImplemented { phase: 9 }` and
     wire it in 09-04).
  4. Compute `mesh` from `ke_cutoff` or `precision` (same wiring note).
  5. Set `_built = true`.
  Also implement `pack`/`unpack`/`dumps`/`loads` in `dumps_loads.rs`
  (port `cell.py:65-155`), reusing `pyscf_gto::dumps_loads` for the molecular fields.
</task>
