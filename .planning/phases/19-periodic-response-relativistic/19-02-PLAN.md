<objective>
**Create five crates and one lint, before anything can be built wrong.**

`pyscf-pbc-{tdscf, gw, adc, x2c, eph}` are each **13 lines** - `src/lib.rs` (6)
plus `src/error.rs` (7), exporting one error enum. Nothing exists.

Two decisions belong here rather than in the nineteen plans downstream:

**libxc.** Four of the five (`adc`, `gw`, `tdscf`, `eph`) depend on
`pyscf-pbc-dft`, which takes `pyscf-dft` with default features, whose default
is `["libxc"]` - the 266-kernel ~6h compile behind `ci.yml:418`'s `if: false`.
> **DEFAULT ACTION:** take `pyscf-pbc-dft` with `default-features = false` in
> all four, and add a `libxc` feature on each that forwards. Developer builds
> stay fast; release builds turn it on.
> **ESCALATE (stop and report) only if:** a Gate-A number moves when the
> feature is off.

**GRAD-10.** `crates/pyscf-grad/src/cphf.rs` is the single matrix-free Krylov
CPHF solver and `crates/pyscf-grad/tests/cphf.rs`'s `single_cphf_impl` guards
against a second one. Phase 19 is exactly when a second would be added - by
someone writing a periodic response and finding the molecular one
inconveniently shaped. Extend the gate now, while it still passes.
</objective>
