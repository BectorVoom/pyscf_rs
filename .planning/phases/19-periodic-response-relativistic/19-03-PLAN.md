<objective>
**Supply a periodic `fvind`; reuse the solver that already exists.**

`pbc/scf/cphf.py` (176 l) and `_response_functions.py` (47 l) are the response
seam every later plan in this phase consumes - `newton_ah` (19-04), `stability`
(19-05), TDA/TDHF (19-06 onward) and GW (19-10 onward).

The equation is the molecular CPHF equation `(1 + A)·z = b` with a k index on
the (vir x occ) rotation space, and `A` applied only through a matrix-free
response operator. `crates/pyscf-grad/src/cphf.rs` already solves exactly that
and its module doc states the rule: MP2 and CCSD each pass their own `fvind`
into the one `solve`.

**This plan adds a `fvind`, not a solver.** 19-02 extended the `single_cphf_impl`
structural gate across the workspace precisely so this boundary is machine-checked.

Note §1.6: `gen_response` is `NotImplemented` on the PBC `KohnShamDFT` base and
only the concrete `RKS` rebinds it. Port that shape - a response supplied
universally would diverge from upstream silently.
</objective>
