<objective>
**G0W0 by analytic continuation - the first of the GW family.**

`pbc/gw/krgw_ac.py` (644 l). The self-energy is evaluated on an imaginary
frequency grid and continued to the real axis by a Pade fit.

Two consequences for the gate. **The grid is part of the method**: a different
number of frequency points is a different answer, so pin it on both sides.
**AC is not CD**: they approximate the same self-energy differently, and 19-01
Task 3 measures the split. If that split exceeds the floor, Gate C is stated
per route - exactly as Phase 16 had to state its CC gate per DF route after
upstream's own routes came out `9.22e-4 Ha` apart.
</objective>
