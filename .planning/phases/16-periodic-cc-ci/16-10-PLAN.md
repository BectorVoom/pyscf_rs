  (`:1417`) and `gen_matvec(left=True)` (`:1466`).

  Each refusal gets an oracle-gated test asserting upstream still raises.
</task>

<task type="auto">
  <name>Task 3: tests</name>
  1. **Koopmans limit** (as 16-09 Task 4.1), oracle-free, written first.
  2. **RHF == GHF roots** — on a closed-shell fixture, 16-10's IP/EA roots
     equal 16-09's to 1e-10. The plan's main correctness gate and it needs no
     PySCF. (This is also the test that would catch a spin-factor error in the
     RHF specialisation, which is the whole point of having a separate module.)
  3. **`vector_size` round-trip** — `amplitudes_to_vector(vector_to_amplitudes(v))
     == v` bit-identically for random `v` of the asserted length, at several
     `kshift`. This is the packing test Task 2 names.
  4. **EE-singlet vs CIS** — with `t1 = t2 = 0`, the EE-singlet roots reduce
     to the CIS roots from `cis_easy`. Oracle-free.
  5. Roots vs upstream (`test_eom_krccsd.py`) at 16-01 Task 4's tolerance;
     upstream asserts these at **3 decimals**.
  6. Determinism (§9.3); peak-memory bound per `16-REVIEW.md §4.1`.
</task>
