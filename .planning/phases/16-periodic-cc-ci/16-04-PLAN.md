<objective>
Port `pyscf/pbc/cc/kintermediates_rhf.py` (926 l) — the k-point RHF CC
intermediates 16-05's `update_amps` contracts against. This is `§8.8`'s plan
16-01, unchanged in scope; what changed is that it now sits on 16-02's complex
arena and is blocked on Phase 15's padding surface.

The molecular analogue already exists — `crates/pyscf-ccsd/src/rintermediates.rs`
ships `cc_Foo`, `cc_Fov`, `cc_Fvv`, `cc_Woooo`, `cc_Wvoov`, `cc_Wvovo`,
`cc_Wvvvv`, `cc_Wvvvv_into`, `Loo`, `Lvv`, `make_tau`. **Read it first and
mirror its module shape**, exactly as `pyscf-ccsd` was told to mirror
`pyscf-mp2`. What it cannot supply is arithmetic: it is f64 throughout
(`16-CONTEXT §1.3`) and carries no k-index.
</objective>

<task type="auto">
  <name>Task 2: the F intermediates</name>
  Port `Foo`, `Fvv`, `Fov` and the `cc_Foo`/`cc_Fvv`/`cc_Fov` variants, plus
  `Loo`/`Lvv`. Each carries a `kconserv`-driven k-loop the molecular version

</task>

<task type="auto">
  <name>Task 3: the W intermediates, with their storage tiers</name>
  `Woooo`, `Wvoov`, `Wvovo`, `Wvvvv` and the `cc_*` variants.

  `kccsd_rhf.py:132-137`, `:179-192` and `:423-455` each carry a
  **three-way branch** on available memory (skip / incore `np.empty` / HDF5
  `create_dataset`). Port all three branches through `KTensor` (16-02 Task 3),
  choosing the tier from the exact byte count. **Do not collapse to incore**:
  `16-REVIEW.md §2.3` shows the port would otherwise ship the spill path
  untested and only discover it at 16-14, which is the shape of 17-12's
  exit-137 failure.

  `Wvvvv` is `nkpts³ · nvir⁴` complex — the phase's largest single tensor.
  On diamond `gth-szv` 2×2×2 that is 2.1 MiB; on `gth-dzvp` 2×2×2 it is
  **1.79 GiB**, and on `gth-dzvp` 3×3×3 it is **68.7 GiB**. The tier branch is
  the whole reason the phase is runnable.
</task>

<task type="auto">
  <name>Task 4: tests</name>
  `crates/pyscf-pbc-cc/tests/kintermediates_rhf.rs`:
  1. **Γ-point reduction** — at `nkpts = 1` with real orbitals, every
     intermediate equals `pyscf-ccsd`'s molecular `rintermediates` value to
     1e-12. This is the highest-value oracle-free test in the plan: it gates
     the k-generalisation against code this project has already shipped and
     tested, with no PySCF run at all.
  2. **momentum conservation** — every assembled block is zero unless its
     k-indices satisfy `kconserv`; assert on a random-but-valid amplitude set.
  3. **Hermiticity / symmetry** of `Woooo` and `Wvvvv` under the index swaps
     upstream's own `check_antisymm_*` helpers assert (`kccsd.py:641-704`).
  4. **tier equivalence** — the same intermediate built incore and spilled is
     bit-identical. Upstream gates its own analogue at 12 decimals
     (`test_krccsd.py:250-256`); this one is same-process, so it is **bit**-
     identical, not 1e-12.
  5. **determinism** (§9.3) — bit-identical at `RAYON_NUM_THREADS` 1 and 8.
  6. an oracle-gated fingerprint against upstream's `lib.fp` of each
     intermediate on `diamond` 2×2×2, at the tolerance 16-01 measured.
</task>
