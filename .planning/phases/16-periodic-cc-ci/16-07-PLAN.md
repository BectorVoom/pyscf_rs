<task type="auto">
  <name>Task 1: the narrow molecular `gccsd` surface</name>
  `crates/pyscf-ccsd/src/gccsd.rs`, ~4 entry points. Its module doc states
  explicitly that this is a **partial** port serving `pbc/cc/kccsd.py`, lists
  what is deliberately absent, and says which phase would complete it — so it
  does not read as an omission (the shape 17-03 used for
  `del self.lattice_symmetry.cell`).

  **`_PhysicistsERIs` is physicists' notation.** `crates/pyscf-ccsd/src/eris.rs`
  ships `ChemistsEris`. These differ by an index transposition and the project
  has already paid **+6 306 866.73 Ha** once for exactly this class of misread
  (14-05's `decompose_j2c`, `16-CONTEXT §3.4`). Name the convention in the type
  name and assert the transposition in a test.
</task>

<task type="auto">
  <name>Task 2: `spatial2spin` / `spin2spatial`</name>
  `kccsd.py:223-331`. These are what make the whole plan checkable: a KGCCSD
  run on a closed-shell system, spin-summed back down, must reproduce 16-05's
  `KRCCSD` result. Port them as an exact inverse pair and test that first.
  Note both take `kconserv`, so they are not the molecular versions with a
  k-index bolted on.
</task>

<task type="auto">
  <name>Task 3: `kintermediates` (spin-orbital) and `KGCCSD`</name>
  `kintermediates.py` (529 l) and `kccsd.py:47-468`. `:414`'s refusal is live
  — port it with the upstream line and an oracle-gated test. `:486` is
  commented out (`#    raise NotImplementedError('Different occupancies...')`)
  and is **not** a refusal; do not port it as one.

  Memory: the spin-orbital basis doubles both `nocc` and `nvir`, so every
  tensor of the `nvir⁴` class is **16×** its RHF counterpart at the same cell.
  `16-REVIEW.md §2.3` gives the numbers; the tier branch is not optional here
  under any fixture.

  Register `scf.kghf.KGHF.CCSD` (`kccsd.py:805`) — Phase 19 reads that surface.
</task>

<task type="auto">
  <name>Task 4: tests</name>
  1. **`spin2spatial(spatial2spin(x)) == x`** bit-identically, and the
     forward direction against a hand-built small case. First test written.
  2. **Closed-shell reduction, no oracle** — `KGCCSD.e_corr` equals 16-05's
     `KRCCSD.e_corr` to 1e-10 on `diamond` 1×1×2. The plan's main correctness
     gate, and it needs no PySCF.
  3. **`check_antisymm_3412` / `_12` / `_34`** (`kccsd.py:641-704`) become
     real assertions on the built ERIs, not ported-but-uncalled helpers.
  4. Physicists'-vs-chemists' transposition asserted explicitly (Task 1).
  5. `e_corr` vs upstream (`test_kgccsd.py`'s systems) at 16-01's tolerance;
     upstream's own suite asserts these at 6 decimals.
  6. Determinism on `t1`/`t2`/`e_corr` at `RAYON_NUM_THREADS` 1 and 8.
</task>
