<task type="auto">
  <name>Task 1: `grad_elec`, gamma, restricted</name>
  Port `rhf.py:33-87`. The assembly, in upstream's order:

  ```python
  h1ao = -mol.pbc_intor('int1e_ipkin', kpt=kpt)
  if mol._pseudo:
      de  = ni.vpploc_part1_nuc_grad(dm0, kpts=kpt.reshape(-1,3))
      de += pp_int.vpploc_part2_nuc_grad(mol, dm0)
      de += pp_int.vppnl_nuc_grad(mol, dm0)
      if hasattr(ni, 'vpplocG_part1') and ni.vpplocG_part1 is None:
          h1ao -= ni.get_vpploc_part1_ip1(kpts=kpt.reshape(-1,3))
  else:
      de  = ni.get_nuc_nuc_grad(dm0, kpts=kpt)
      h1ao -= ni.get_nuc_ip1(kpts=kpt)
  de += _contract_vhf_dm(mf_grad, np.add(h1ao, vhf), dm0) * 2
  de += _contract_vhf_dm(mf_grad, s1, dme0) * -2
  ```

  Three things a tidy port loses:
  * the `get_vpploc_part1_ip1` subtraction is **conditional on
    `ni.vpplocG_part1 is None`** (`:68-70`) — i.e. it applies only when the
    part-1 potential was *not* precomputed. Ported unconditionally it
    double-counts;
  * the pseudopotential and all-electron branches take **different** paths for
    both `de` and `h1ao` — there is no shared prefix to factor out;
  * `:76` unbinds `h1ao = s1 = vhf = dm0 = dme0 = None` before the atom loop.
    That is upstream freeing full-grid arrays as early as it can, and it is a
    hint about where the memory sits, not stylistic noise.

  **Refusals, both ported verbatim**: a numint that is not `MultiGridNumInt2`
  (`:46-47`) and a non-gamma `kpt` (`:78-79`).
</task>
