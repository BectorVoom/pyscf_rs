  <name>Task 1: the two floors D-PBC-31's biggest rulings are gated on</name>
  Both of these decide whether a ruling ships, so they are measured here and
  not argued later.

  1. **Gate A, per tier** (clause 1). `18-CONTEXT §2.3` now states Gate A as
     **A1 = 1e-9 / A2 = 2e-9 / A3 = 1e-8**, inherited from sixteen upstream
     test methods (twenty-five assertions by line: 13 tests/22 assertions at
     A1, 2 tests/2 assertions at A2, 1 test/1 assertion at A3). Run upstream's
     own `test_rks_stress.py` component
     tests and record the *realised* residual for each — not the asserted
     bound — on the §9.2 reference cells as well as upstream's own
     `np.random.seed(5)` lattice. The margin between realised and asserted per
     tier is what tells 18-11/18-12/18-13 whether A1 is reachable on this
     port's cells or whether a named exception is needed.

  2. **The Parseval residual for clause 7's fused `hcore` contraction.**
     `krhf.hcore_generator` builds `(3,nkpts,nao,nao)` per atom only for
     `grad_elec:63` to reduce it to three numbers, and
     `Σ_ij vloc[k,ij]·dm0[k,ji] = Σ_g vloc_R[g]·ρ_k[g] = Σ_G conj(vloc_g[G])·ρ_k[G]`.
     Compute all three forms in NumPy on a reference cell and record
     `|real-space − G-space|` relative. Predicted ~1e-13; **G-space and
     real-space are different summations and this is NOT bit-identity**.
     18-05 Task 3 gates against this number, so a measured value far from the
     prediction is a finding that stops the ruling.
</task>
