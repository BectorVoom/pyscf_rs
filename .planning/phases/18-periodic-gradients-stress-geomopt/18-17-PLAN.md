**Three measurements, each of which decides a ruling that would otherwise be
argued.**

Split out of 18-01 so one session runs one family. These three share a method —
instrument, run, record — and none of them touches a gate tolerance:

1. `_contract_vhf_dm`'s screening default (`pbc/grad/rhf.py:30` ships
   `SCREEN_VHF_DM_CONTRA = True`). **18-18 Task 3 takes its default from this
   number**, not from transcribing upstream.
2. The peak-RSS sizings `18-REVIEW §3.1` derived on paper. 18-04's `blksize`
   re-derivation uses the realised buffer multiplicity.
3. The clause-5 fusion question: is the strain-AO cost arithmetic or buffer
   traffic? This repo has already measured that buffer traffic dominates its
   collocation kernels; confirm or refute for this shape.

**This plan writes no Rust.**
</objective>
