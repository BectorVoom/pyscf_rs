<objective>
**This plan exists because `PBC-MASTER-PLAN §8.9` forgot it.** Its eight-row
table lists `geom`/`tables`/`group` and `space_group`/`symmetry`, and never
mentions `pyscf/pbc/symm/basis.py` (161 l). It is not optional:

* `khf_ksymm.eig` (`khf_ksymm.py:104-119`) reads `cell.symm_orb` and
  `cell.irrep_id` **directly**, and block-diagonalises the Fock matrix in that
  basis.
* They are produced by `Cell._build_symmetry` → `symm_adapted_basis`
  (`cell.py:1515-1527`, `basis.py:109`).
* `ksymm_scf_common_init` (`khf_ksymm.py:142`) defaults `use_ao_symmetry = True`
  — this is the **default** SCF branch.
* Upstream gates it: `scf/test/test_khf_ksym.py:94-100` (`test_krhf_symorb`),
  `dft/test/test_krks_ksym.py:131-137` (`test_krks_symorb`).

Without this plan the phase can ship only `use_ao_symmetry = false`. That is an
acceptable *intermediate* state — 17-07 must work in both modes anyway — but it
has to be a stated choice, not a gap discovered when `eig` reaches for a field
that does not exist.
</objective>

<tasks>

<task type="tdd">
  <name>Task 1: _symm_adapted_basis — the projection</name>
  `basis.py:26-92`. For one IBZ k-point: take the little co-group `pg`, its
  space-group ops `spg_ops` and the `Dmats` from 17-03, project the AO basis onto
  each irrep, and return the surviving columns with their irrep labels.

  Two details that decide correctness:

  * The projector is built from the **little co-group at that k-point**, not the
    full point group — which is why `little_cogroups` / `little_cogroup_rep`
    (`kpts.py:1084-1126`) are 17-05's job and this function takes them as input.
    Do not re-derive them here.
  * The per-op phase from `_get_phase` (`symmetry.py:226`) enters the projector.
    A k-point where the phase is dropped still produces an orthonormal basis —
    it is just the *wrong* basis, and the SCF converges to a different state.
    That failure is silent, so the phase must be threaded and asserted.

  `tol = 1e-9` (`basis.py:26`) is the rank threshold; keep it as a named
  constant, not a literal.
</task>

<task type="tdd">
  <name>Task 2: _gram_schmidt</name>
  `basis.py:93-108`. Ordinary modified Gram–Schmidt with the same `tol = 1e-9`
  drop.

  The order of the input vectors determines which columns survive a rank
  deficiency, and therefore the column order of `symm_orb`, which
  `khf_ksymm.eig` slices by irrep. Preserve upstream's order exactly. As
  everywhere in this phase, a `HashSet`/`HashMap` iteration in the path is a
  defect.
</task>

<task type="tdd">
  <name>Task 3: symm_adapted_basis and Cell::build_symmetry</name>
  `basis.py:109-161` loops `_symm_adapted_basis` over `kpts.kpts_ibz` and returns
  `(symm_orb, irrep_id)`, one entry per IBZ k-point.

  Wire it into `Cell`:
  * add `symm_orb: Option<Vec<CTensor>>` and `irrep_id: Option<Vec<Vec<i32>>>`
    as plain data on `Cell` (same layering argument as 17-03 Task 7 — the data
    lives in `pyscf-pbc-gto`, the producer in `pyscf-pbc-symm`).
  * add `Cell::build_symmetry(&mut self, kpts: &KPoints)`, mirroring
    `cell.py:1515-1527`. Upstream raises when handed a plain k-point array
    instead of a `KPoints` (`:1526-1527`); port the refusal, it is the only
    guard against silently symmetrising nothing.

  **Ordering constraint:** `KPoints` is 17-05. This task therefore lands the
  `Cell` fields and the `pyscf-pbc-symm` entry point now, and 17-05 connects
  them. If 17-05 slips, the fields sit unused — which is fine and is *not* the
  "container with no caller" problem 15-CONTEXT §1.1 warned about, because the
  test in Task 4 exercises them directly.
</task>

<task type="tdd">
  <name>Task 4: the tests that need no oracle</name>
  `tests/basis.rs`, on `si` and `diamond` at `[2,2,2]` and `[3,3,3]`:

  1. **Orthonormality in the S metric:** `symm_orb[k]ᴴ · S(k) · symm_orb[k] == I`
     to 1e-12. This is the identity that *defines* a symmetry-adapted basis and
     it catches a dropped phase, a bad Gram–Schmidt and a transposed `Dmat` in
     one assertion. It is this plan's analogue of 14-05's `V j2c Vᴴ = I`.
  2. **Completeness:** `Σ_ir (columns in irrep ir) == nao` at every IBZ k-point.
     A projector that loses a column loses electrons.
  3. **Block-diagonality:** `symm_orb[k]ᴴ · F(k) · symm_orb[k]` is
     block-diagonal by `irrep_id` to 1e-11, for `F` the converged Fock of a
     full-BZ run. This is the property `khf_ksymm.eig` *relies on*; asserting it
     here means a failure in 17-07 can be localised immediately.
  4. **Invariance:** applying any little-co-group op to `symm_orb` reproduces it
     up to the irrep's character.

  Oracle test (tier 2): `irrep_id` multiset per k-point against upstream's, and
  the `test_krhf_symorb` energy once 17-07 lands.
</task>
