<objective>

**Implement the default `minao` init guess so DF-HF (and RHF) work out-of-the-box —
the gaps-phase follow-up to 03-12.**

03-12 proved DF-HF converges, but only via the explicit `1e` guess; the DEFAULT
`minao` mode is `NotYetImplemented`, so `RHF(mol).density_fit().kernel()` with
defaults errors. This plan implements minao, faithfully porting
`pyscf/scf/hf.py:init_guess_by_minao`:

1. Per element, get the l-shell occupations from `frac_occ` over a ported
   `NRSRHF_CONFIGURATION` table (electrons per [s,p,d,f] per element).
2. Build an ANO-derived minimal reference Mole (`'ano'` basis loads in pyscf-rs)
   with an occupation vector `occ` (2 for doubly-occupied valence AOs, `frac`
   for the partially-occupied frontier, 0 elsewhere).
3. `mo = S_working⁻¹ · S_cross` where `S_cross = <working|minao>` (NEW
   `intor_cross`), then `dm = mo · diag(occ) · moᵀ`.

**Gold-standard verification:** byte-match the upstream docstring H2 density
`[[0.94758917,0.09227308],[0.09227308,0.94758917]]`.

**Known caveat (to validate + document):** the vendored `ano.dat` loads H with
one contraction per l. Atoms whose minimal occupation needs >1 contraction per l
(e.g. C's 1s+2s) may be under-resolved by this data — verify on H2/H2O, document
the heavier-atom status honestly (the algorithm is correct; the ANO data
coverage is the open question).

No new crate dep; libxc NEVER compiled.
</objective>

<interfaces>
**Upstream `init_guess_by_minao` (pyscf/scf/hf.py) — the port target:**
- `frac_occ(symb, l)`: `ne = NRSRHF_CONFIGURATION[Z][l]; nd = (2l+1)*2; ndocc = ne//nd; frac = (ne/nd - ndocc)*2`.
- reference occ per l: `[2]*ndocc + [frac]` repeated over `(2l+1)` m-values (only if ne>0).
- `mo = project_mo_nr2nr(pmol, eye(pmol.nao), mol)` = `cho_solve(S_working, S_cross)`, `S_cross = <working|minao>`.
- `dm = (mo*occ) @ moᵀ`.

**NEW `intor_cross` (pyscf-gto):** arity-2 integral between two DIFFERENT built
Moles over a combined basis (reuse the 05-08 `build_int3c2e_combined_basis`
pattern → factor a shared `build_combined_basis(mol_a, mol_b)` helper). For
`int1e_ovlp_sph`: iterate i∈A-shells, j∈B-shells, evaluate the pair, stitch the
OFF-DIAGONAL block into `[nao_a, nao_b]` F-order. Returns `IntorOutput`.

**pyscf-algebra:** `solve_linear(a, b, n)` (faer LU) — use for `S_working⁻¹ S_cross`
column-by-column, OR `eigh`/Cholesky. Reductions via oracle_dot/oracle_sum.

**ANO load:** `BasisInput::Name("ano")` (→ ano.dat). H = 16 AOs, 1 ctr per l (s,p,d,f).
For H, only l=0 occupied (occ=1.0) → reference is effectively the s function.

**Existing:** `default_get_init_guess` matches `InitGuessMode::Minao =>
Err(InitGuessNotYetImplemented(...))` — replace with `init_guess_by_minao(mol)`.
`init_guess_by_1e` is the working precedent (build hcore, eig, aufbau, make_rdm1).
