<task type="auto">
  <name>Task 1: gdf::cderi_store — the on-disk 3-index tensor</name>
  Upstream's layout, which Phase 15/16 will read, is
  `{dataname}/{ki*nkpts+kj}/{istep}` with `kpts` and `aosym` at the file root,
  plus a `{dataname}-` sibling group for the 2-D negative branch.

  * `CderiStore` owns the file handle, writes one `(naux, ncol)` block per
    `(kpair, istep)`, and reads back with `sr_loop`'s blocking.
  * `sr_loop(kpti_kptj, max_memory, compact, blksize, aux_slice)` — PORT
    `df.py:338-400`. Yields `(LpqR, LpqI, sign)`. The `compact`/`unpack`
    logic is the `s2 ↔ s1` conversion: `pack_tril` when the stored block is
    `nao²` and `compact`, `unpack_tril` (with `ANTIHERMI` on the imaginary
    part) when it is packed and the caller wants square. **Getting
    `ANTIHERMI` wrong is invisible at gamma** — where the imaginary part is
    zero — and wrong everywhere else. Test at `k ≠ 0` (Task 5.4).
  * `get_naoaux()` — PORT `df.py:568-611`, including the assertion that every
    k-pair has the same `naux` (the eigen-decomposed metric can drop different
    ranks per k-point; upstream raises rather than silently truncating).
  * `cderi_array` / `_load3c` / `_KPair3CLoader`: implement only what
    `sr_loop`, 14-04 and 14-05 actually call. Anything else returns
    `NotYetImplemented { phase: 15 }` naming its consumer.
  * RAII: the temp `_cderi` file is deleted on drop unless
    `_cderi_to_save` was set, matching `pyscf-ccsd`'s spill pattern.
</task>

  * `get_pp_loc_part1(mesh, with_pseudo)` — the reciprocal-space half, through
    Phase 13's `FtKernel`/`ft_loop`.
  * `get_nuc` = `get_pp_loc_part1(with_pseudo = false)`;
    `get_pp` = `get_pp_loc_part1()` + `get_pp_loc_part2()` + `get_pp_nl()`.
    **Use `pyscf_pbc_gto::pseudo::vloc_part2::get_pp_loc_part2`, the Phase-10
    route** — not a re-derivation. Phase 13 measured that upstream's own
    `_IntPPBuilder.get_pp_loc_part2` and `pp_int.get_pp_loc_part2` disagree by
    **1.7933e-9**, and that the `pp_int` route is the one `fft.get_pp` agrees
    with. Assert that substitution in the test suite here too, exactly as

    **F-order**; transpose before adding.
</task>
