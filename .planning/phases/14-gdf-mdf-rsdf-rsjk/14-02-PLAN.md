<objective>
`_CCGDFBuilder`: the compensating-charge scheme that makes a Gaussian density
fit possible under periodic boundary conditions, and the `make_j3c` driver that
turns `(μν|P)` plus a metric into `cderi`.

Port target: `pyscf/pbc/df/gdf_builder.py` in full **except** `_outcore_dd_block`,
`_int_dd_block` and the `merge_dd` branches (D-PBC-23), plus the four methods
`_CCGDFBuilder` inherits from `rsdf_builder._RSGDFBuilder`:
`decompose_j2c` (:215), `cholesky_decomposed_metric` (:222),
`eigenvalue_decomposed_metric` (:231), `gen_uniq_kpts_groups` (:830) and
`make_j3c` (:889).

**Why the compensating charge exists.** A 3-centre integral against a *charged*
auxiliary function decays as `1/R`, so its lattice sum does not converge. GDF
subtracts a smooth Gaussian of the same charge — whose Fourier transform is
analytic — leaving a short-ranged real-space part, and adds the subtracted piece
back in reciprocal space through `ft_ao`. `fuse_auxcell` builds the fused
(aux + model-charge) basis; `fuse` performs the subtraction; `add_ft_j3c` puts
the long-range half back.
</objective>

  <name>Task 4: gdf_builder::fuse — the compensating charge</name>
  * `make_modchg_basis(auxcell, smooth_eta)` — PORT `:766-800`. One `s`-…-`l`
    shell per `(atom, l)` present in `auxcell`, all sharing exponent `eta`,
    normalised `half_sph_norm / gaussian_int(2l+2, eta)`, with
    `chgcell.rcut = _estimate_rcut(eta, l_max, 1.0, auxcell.precision)`.
  * `fuse_auxcell(auxcell, eta) -> (fused_cell, Fuse)` — PORT `:801-886`.
    `fused_cell = concat(auxcell, chgcell)`, `rcut = max` of the two. Measured:
    `fused_cell.nao = 126` / `nbas = 42` on diamond, `32` / `12` on He-fcc.
  * `Fuse` is a struct, not a closure: it owns `modchg_offset[(ia, l)]`,
    `aux_loc`, `naux`, and applies `Lpq[i0..i1] -= chgLpq[p0..p0+nd]` for every
    aux shell that has a model-charge partner, over `axis ∈ {0, 1}`.
    **The cartesian branch (`auxcell.cart`) additionally runs a cart→sph
    contraction per shell** (`CINTc2s_ket_sph`); this port's cells are spherical,
    so implement the spherical branch and return
    `NotYetImplemented { phase: 19, what: "cartesian fused auxcell" }` for
    `cart = true` rather than silently taking the spherical path.
  * `auxbar(fused_cell)` — PORT `:729-765`. `vbar[aux_loc[i]] = -1/e` for
    single-primitive `l = 0` shells, the contracted form otherwise, times
    `π/vol`; zero when `dimension < 2` or `omega < 0`. Measured after `fuse`:
    12 non-zeros / ‖·‖ 0.23012787965177506 on diamond 2×2×2, 4 / 0.3187837520926407
    on He-fcc.
  * `_compensate_nuccell(cell, eta)` — PORT `:918-931`. One `s` Gaussian of
    exponent `eta` per atom. Used by 14-03's nuc builder, defined here.
</task>

     compensating charge is wrong and every number after it is meaningless.

     `exclude_dd_block=False`**, at **1e-11**, on both systems. Additionally record — and assert as an upper bound, not a
     target — the deviation vs upstream's DEFAULT (`True`): ≤ 3e-8 on diamond,
