<objective>
**Close the wall that has never been enforced — while it still passes.**

D-PBC-14 says every `pyscf-pbc-*` crate is pyo3-free. Today that is **true**:
zero PBC crates name `pyo3`. But **nothing enforces it**.
`xtask/src/bin/check_dependency_wall.rs:29-52` polices only `cubecl-*` (plus
`cube-math`), with an allowlist of `pyscf-algebra`, `pyscf-runtime`,
`pyscf-kernels`, `pyscf-bench`. The pyo3 rule lives in plan prose —
`04-09-PLAN.md:25,125`, `03-03-SUMMARY.md:41,79`.

This phase is exactly when that invariant is most likely to break by accident:
someone binding 29k lines of CC reaches for `#[pyclass]` in the method crate
because it is closer to the data. Add the rule now, while the tree is clean, so
the lint's first run is green and its first red is a real violation.

This plan is deliberately tiny and independent of every binding plan.
</objective>
