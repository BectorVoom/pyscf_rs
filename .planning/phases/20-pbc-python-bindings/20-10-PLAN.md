<objective>
**Bind the density-fitting layer — five builders, one wrapper.**

`pyscf-pbc-df` is 15,255 lines, but its *binding* surface collapses because of a
decision already made: **`trait PeriodicDf` (`src/traits.rs:102-132`) is
object-safe**, and every SCF/KS driver stores `Box<dyn PeriodicDf>` and
constructs via `from_df`.

| upstream | Rust | file:line |
|---|---|---|
| `FFTDF` | `Fftdf` | `src/fftdf.rs:76`, `with_mesh:130` |
| `AFTDF` (alias `PWDF`) | `Aftdf` | `src/aftdf.rs:53`, `with_mesh:97` |
| `GDF` (alias `DF`) | `Gdf` | `src/gdf/mod.rs:64`, `with_cderi:118`, `load_cderi:153` |
| `MDF` | `Mdf` | `src/mdf/mod.rs:72` |
| `RSDF` / `RSGDF` | `Rsdf` | `src/rsdf.rs:56` |

`PBC-MASTER-PLAN:1909` states the contract this plan owes:
*"`mf.with_df = AFTDF(cell, kpts)` must work from Python. Phase 20 owns this."*
That means the object must be **assignable onto a driver after construction** —
settle the ownership shape here, before four drivers depend on it in 20-12/20-13.
</objective>
