<objective>
**Make the edge of the port visible.**

`python/pyscf/pbc/__init__.py` is a `pkgutil.extend_path` passthrough. Measured
2026-09-12:

```
pyscf.pbc.scf = /home/user/Documents/workspace/pyscf_rs/pyscf/pbc/scf/__init__.py
```

Every `pyscf.pbc.*` name this port does not explicitly shadow resolves to
**vendored upstream Python**. After 20-09…20-15, `pyscf.pbc.scf.KRHF` will be
Rust while `pyscf.pbc.grad.krhf` is still upstream Python — silently, in the
same session, with no diagnostic.

**Ten upstream packages are fully unported** — `grad`, `geomopt`, `tdscf`, `gw`,
`adc`, `x2c`, `eph`, `mpicc`, `mpitools` (nine mapping to 13-line stub crates,
with `mpicc`+`mpitools` collapsing into `pyscf-pbc-mpi`) and `tddft` (no crate
at all). **Six more are partially covered**: `scf` (`newton_ah` — no match
anywhere in the Rust tree — plus `stability`, `cphf`, `_response_functions`,
`scfint`, `kuhf_ksymm`, `kghf_ksymm`), `tools` (`k2gamma`, `lattice`,
`pyscf_ase`, `pywannier90`, `print_funcs`, `tril`), `gto` (`ecp`), `symm`
(`pyscf_spglib`), `ci` (`cisd`), `lib` (`arnoldi`).

> **DEFAULT ACTION: announced passthrough.** Keep `pkgutil.extend_path` so
> upstream scripts still run, emit a one-time `UserWarning` the first time an
> unported family is reached, and expose `pyscf.pbc.which_impl(name)`.
>
> **ESCALATE (stop and report) only if:** the warning breaks an existing test
> that asserts clean stderr.

Hard refusal was rejected — it breaks the milestone goal outright. Silent
passthrough was rejected — it is the status quo, and it is what let a vacuous
gate stand for a whole milestone.
</objective>

<task type="auto">
  <name>Task 1: write the shims</name>
  `python/pyscf/pbc/{gto,scf,dft,df,symm,lib,tools,mp,cc,ci}/__init__.py` in the
  established one-line form:

  ```python
  from pyscf._native.pbc.scf import KRHF, KUHF, KROHF, KGHF
  __all__ = ["KRHF", "KUHF", "KROHF", "KGHF"]
  ```

  Re-export the **same object** — never wrap, or 20-18's identity gate fails.
  Bind the aliases as aliases: `DF = GDF`, `PWDF = AFTDF`.
</task>

<task type="auto">
  <name>Task 2: port upstream's Python-level dispatch</name>

<task type="auto">

  `python/pyscf/pbc/_unported.py` listing all sixteen entries with a status of
  `"upstream"` (ten) or `"partial"` (six), each naming the upstream module and,

  `which_impl(name) -> "native" | "partial" | "upstream"`.

  a warning on every call would drown a long SCF.
</task>

</task>
