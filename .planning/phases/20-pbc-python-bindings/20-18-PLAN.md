<objective>
**Verify the phase against a gate a no-op cannot pass.**

`ROADMAP.md:466` stated the Phase-20 gate as *"an unmodified upstream
`pyscf.pbc` script runs on pyscf-rs"* — satisfied today, with zero work, by the
`pkgutil` passthrough. 20-01 restated it as the identity contract. **This plan
proves the restatement discriminates**, by running the new gate against the
pre-20-09 tree and confirming it fails there.

Then two demonstrations. First, that the bindings resolve to Rust — the Phase-3
identity contract (`test_overlay_resolution.py:20`). Second, the milestone
claim: a real upstream periodic script runs unmodified against them.

The upstream-suite target is **≥ 80% pass**. That number is meaningless without
its denominator, and `pytest.ini` already removes several PBC files from
collection. Those exclusions belong in the reported denominator, not applied
underneath it.
</objective>
