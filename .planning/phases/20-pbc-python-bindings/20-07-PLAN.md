<objective>
**Build the one genuinely new piece of the binding boundary.**

Everything else in this phase copies a molecular precedent. This does not.
`crates/pyscf-py/src/numpy_io.rs` handles only **real** arrays —
`to_density:22`, `to_mo_coeff:53`, `density_to_pyarray:91`,
`mo_coeff_to_pyarray:107`, `slice_to_pyarray1:125`. Every periodic quantity is
**complex** and **per k-point**: `KMats = Vec<CTensor>`
(`pyscf-pbc-scf/src/types.rs:17`), `CTensor { re, im }` planar by D-PBC-02 so
every existing real cubecl kernel is reused unchanged.

**The precedent exists — copy it, do not reinvent.** `crates/pyscf-py/src/gto.rs:98-111`:

```rust
let data: Vec<Complex64> = out.re.iter().zip(out.im.iter())
    .map(|(&re, &im)| Complex64::new(re, im)).collect();
let arr = ArrayD::from_shape_vec(IxDyn(&out.shape).f(), data)?;
```

The `.f()` is the whole trick: PBC matrices are column-major, and omitting it
silently transposes rather than erroring.

This plan is `tdd` — write `tests/complex_roundtrip.rs` first.
</objective>
